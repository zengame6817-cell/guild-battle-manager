ギルド対戦管理 v2.1（コンパクトUI＋高速同期）
================================================

今回の変更
----------
・余白を大幅削減
・PCはほぼ1行表示
・スマホはコンパクト2～3段表示
・2秒ごとに「更新番号」だけ確認
・更新番号が変わった時だけ全データ取得
・ブラウザから変更した本人には、更新レスポンスで最新データを即返却
・スプレッドシートを直接編集した場合も onEdit で更新番号を変更
・タブがバックグラウンドの時はポーリング停止
・復帰時に即同期
・一時的な通信失敗では表示中データを消さず「再接続中」にする

重要：Apps Script側も更新が必要です
------------------------------------
1. 本番スプレッドシート → 拡張機能 → Apps Script
2. 現在の API.gs を開く
3. 中身をすべて消す
4. 「API_v2.1.gs」の内容を丸ごと貼る
5. 保存
6. デプロイ → デプロイを管理 → 鉛筆
7. バージョンを「新バージョン」にしてデプロイ

※ URLは同じままでOKです。

GitHub側
--------
次の4ファイルを上書きしてください。

index.html
style.css
app.js
config.js

Commit後、GitHub Pages反映を待って Ctrl+F5。

確認
----
固定API URL?action=ping
を開いて

"API v2.1 is working"

が出れば新API反映済みです。

同期の仕組み
------------
通常時：
ブラウザ → 2秒ごとに更新番号だけ問い合わせ

変更なし：
全データを読み込まない

変更あり：
全データを再取得

スプシを直接編集：
onEdit → 更新番号変更 → 開いているブラウザが約2秒以内に検知

ブラウザから変更：
保存時に最新データを一緒に返すので、操作した本人はほぼ即時反映
他の人は約2秒以内に反映
